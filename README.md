# Eco-Patrol — карта эко-проблем Алматы

Учебный проект программы «Таза Қазақстан»: интерактивная карта, сообщения с фото,
поиск адресов, геолокация, фильтры и статусы. Карта занимает всю рабочую область,
а панель меток можно скрыть и вернуть кнопкой в шапке.

## Быстрый запуск

Нужен Python 3. Скачайте и распакуйте **весь проект**, затем выполните:

```bash
cd eco-patrol
python start.py
```

На macOS/Linux при необходимости используйте `python3 start.py`, на Windows —
`py start.py`. Браузер откроется автоматически; оставляйте терминал открытым.

Карта и поиск требуют интернета и доступа к `unpkg.com`,
`tile.openstreetmap.org`, `nominatim.openstreetmap.org`. API-ключи и установка
пакетов не нужны. Простое открытие HTML через `file://` даёт только предпросмотр.

Приложение написано на HTML, CSS и JavaScript с ES-модулями без сборщика.
Метки сохраняются в localStorage вашего браузера; общего серверного хранилища нет.

Подробное описание модулей, сценарий защиты, вопросы преподавателя и способы
запуска находятся в [документации проекта](eco-patrol/README.md).

## Публикация на Netlify

Сайт статический: на сервере не нужны Python, Node.js или API-ключи приложения.
В Netlify импортируйте репозиторий `Tailaining/Eco-Patrol` из GitHub:

- Ветка: `main`.
- Команда сборки: оставить пустой.
- Папка публикации: `eco-patrol`.

Эти настройки также записаны в `netlify.toml`. После настройки Git-интеграции
обновления ветки `main` будут автоматически публиковаться на сайте.

Готовый архив сайта для ручной загрузки: [Eco-Patrol-v3-netlify-site.zip](deploy/Eco-Patrol-v3-netlify-site.zip). Внутри `index.html` расположен в корне; архив не требует Python или сборки.

Для ручной публикации откройте [Netlify Drop](https://app.netlify.com/drop)
и перетащите **папку `eco-patrol`**, в которой непосредственно находится
`index.html`. ZIP с внешним каталогом всего репозитория сначала распакуйте.
При ручной публикации обновления тоже загружаются вручную в тот же проект Netlify.

Скопируйте фактический HTTPS-адрес после завершения публикации. Откройте карту,
выберите место кликом или поиском, заполните форму и сохраните метку. Кнопка
местоположения попросит разрешение браузера. Типы и статусы выбираются в панели.
Метки и фото остаются в браузере конкретного посетителя; публикация сайта
не создаёт общую базу сообщений между пользователями.
