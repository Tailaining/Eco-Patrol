# Eco-Patrol

**Интерактивная карта эко-проблем Алматы** — учебный проект в контексте программы «Таза Қазақстан». Житель отмечает свалку, переполненную урну, сломанную скамейку или место для субботника, добавляет описание и фото. Карта занимает всю рабочую область под шапкой; компактная панель меток находится поверх карты и сворачивается кнопкой в шапке или крестиком. Данные сохраняются в браузере.

> **Место для скриншота.** После запуска сделайте снимок карты со списком меток и открытым popup. Пока изображение не добавлено, здесь оставлена текстовая заглушка.

Пять начальных меток — вымышленные учебные примеры, а не сообщения о реальных происшествиях. Eco-Patrol не отправляет обращения городским службам.

## Просмотр и запуск без сборки

Проект написан на HTML5, CSS3 и обычном JavaScript. Сборщик, `npm install`, backend и API-ключи не нужны. Единственная внешняя библиотека — **Leaflet 1.9.4**, подключённая с `unpkg.com` с проверкой целостности SRI. Для карты и поиска адресов нужен интернет.

Скопируйте **весь каталог `eco-patrol`**, включая `css`, `js`, `assets` и `start.py`. После двойного клика по `index.html` доступен локальный предпросмотр: карта, пять учебных маркеров и сворачиваемая панель. Для этого нужен интернет. Изменение меток, поиск, геолокация и импорт/экспорт в предпросмотре отключены: браузер ограничивает ES-модули на `file://`.

В `index.html` есть резервная копия оформления, поэтому даже отдельно скопированный HTML сохраняет внешний вид. Для карты и скриптов нужна полная папка, а для **всех функций** — запуск через HTTP. API-ключи не требуются; исходная функциональность доступна в полном режиме.

### На своём компьютере: одна команда

Если установлен Python 3, откройте терминал в каталоге `eco-patrol` и выполните:

```bash
python start.py
```

На macOS / Linux команда обычно называется `python3`:

```bash
python3 start.py
```

`start.py` использует только стандартную библиотеку Python, печатает адрес и открывает полный проект в браузере. По умолчанию используется порт **4173**, чтобы после перезапуска сохранялся тот же адрес и доступ к меткам. Если порт занят, программа выбирает свободный и предупреждает об отдельном хранилище. Если автоматическое открытие браузера недоступно, скопируйте напечатанный адрес вручную. Сервер остановится по `Ctrl+C`.

### В текущей облачной среде

Python уже доступен; дополнительные пакеты устанавливать не требуется:

```bash
cd /workspace/Eco-Patrol/eco-patrol
python3 -m http.server 4173 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:4173/` в браузере на той же машине. В удалённой облачной среде доступ из браузера вашего компьютера зависит от её средств просмотра или перенаправления портов; сам сервер не создаёт публичную ссылку. Сервер остановится по `Ctrl+C`.

### Другие способы: npx serve и Live Server

Если установлен Node.js, откройте терминал в каталоге с `index.html`:

```bash
cd eco-patrol
npx serve . -l 4173
```

Первая команда `npx serve` может скачать утилиту статического сервера. Она не добавляет зависимостей в приложение. Откройте адрес, который напечатает сервер.

Другой вариант: в VS Code установите расширение **Live Server**, откройте каталог `eco-patrol` и выберите **Open with Live Server** для `index.html`.

Геолокация обычно доступна только на **HTTPS** или **localhost / 127.0.0.1**. На обычном HTTP по IP другого компьютера браузер может отказать ещё до запроса разрешения. Координаты также зависят от устройства и его настроек.

## Возможности

- Три способа выбрать точку: клик по карте, поиск адреса в Казахстане, кнопка «Моё местоположение».
- Форма с проверкой заголовка, описания и фотографии; превью и уведомления об ошибках.
- Цветные маркеры и popup с фото, адресом, датой, статусом и удалением с подтверждением.
- Фильтры по типу и статусу, поиск по заголовку и описанию с задержкой 300 мс.
- Счётчики всех меток: всего, новые, в работе и решённые. Фильтры меняют карту и список, но не эти общие счётчики.
- Демо «🎤 Демо: спросить зал»: поиск выбранного аудиторией адреса и сохранение зелёной метки «Здесь нужен субботник!».
- Экспорт JSON и импорт с проверкой всей структуры до сохранения.
- Карта на всю рабочую область и плавающая панель шириной 340 px на большом экране; панель можно скрыть и вернуть на любом экране.
- Адаптивная мобильная панель, нативные модальные окна `<dialog>`, подписи для вспомогательных технологий и видимый фокус клавиатуры.

Статус меняется по циклу: **Новая → В работе → Решена → Новая**. После добавления метки фильтры сбрасываются, чтобы новая точка сразу была видна.

## Архитектура

`main.js` связывает модули через функции обратного вызова. `ui.js` отвечает за элементы страницы, `reports.js` — за операции с метками, `storage.js` — за проверку модели и запись. UI не обращается к `localStorage` напрямую.

| Модуль | Назначение и основные функции |
| --- | --- |
| `config.js` | Центр Алматы `[43.2389, 76.8897]`, zoom `12`, типы и статусы, параметры фото, ключ хранилища, пять примеров. |
| `utils.js` | `createId`, `formatDate`, `escapeHtml`, `debounce`, безопасное создание DOM-узла `element`. |
| `storage.js` | `validateReport` / `validateReports` проверяют модель; `loadReports` / `saveReports` читают и записывают JSON. |
| `reports.js` | `createReportsService` возвращает операции `init`, `list`, `create`, `remove`, `setStatus`, `import`, `filter`, `counts`, `subscribe`. Хранит текущее состояние в замыкании. |
| `image.js` | `compressImage` читает файл через `FileReader`, открывает изображение и сжимает его через canvas. |
| `geocoder.js` | `createGeocoder` возвращает асинхронный поиск адреса, проверяет ответ, ограничивает частоту и обрабатывает тайм-аут. |
| `geolocation.js` | `getLocation` оборачивает `getCurrentPosition` в Promise и переводит ошибки браузера в понятные сообщения. |
| `map.js` | `initMap` создаёт Leaflet-карту. API `render`, `focus`, `preview`, `clearPreview`, `startPicking`, `home`, `resize` управляет маркерами и картой. |
| `ui.js` | `initUI` связывает форму, фото, список, фильтры, импорт и сворачиваемую панель; `toast`, `openDialog`, `closeDialog` управляют уведомлениями и окнами. |
| `demo.js` | `initDemo` связывает окно демонстрации с тем же геокодером и сервисом меток. |
| `main.js` | Точка входа: создаёт сервисы, подписывает интерфейс на изменения, подключает события поиска, геолокации и экспорта. |
| `file-preview.js` | Обычный скрипт выбора режима: на HTTP подключает `main.js` как ES-модуль, а на `file://` показывает карту и встроенные примеры без загрузки модулей. Не участвует в бизнес-логике и сохранении меток. |

`start.py` — небольшая утилита локального HTTP-сервера и открытия браузера; это не backend приложения, данные он не сохраняет.

CSS разделён по задаче: `base.css` — переменные, сброс и типографика; `layout.css` — шапка, плавающая панель, карта и размеры экранов; `components.css` — формы, карточки, кнопки, popup, окна и анимации. `index.html` содержит семантическую разметку, подключения ресурсов и учебный JSON для предпросмотра.

Встроенный резерв CSS расположен **перед** ссылками на внешние стили. При обычном запуске правьте файлы в `css/`: они подключены позже и задают оформление. После изменения дизайна поддерживайте резерв в `index.html` актуальным, копируя содержимое трёх CSS-файлов в том же порядке. Это копия для просмотра отдельного HTML, обязательного шага сборки нет.

Пример потока данных при добавлении:

```text
Клик Leaflet → map.js → callback main.js → ui.openForm()
Отправка формы → reports.create() → validateReport() → saveReports()
Успешная запись → подписчики → ui.render() и map.render()
```

Сначала выполняется запись, затем обновляется память и экран. Если `localStorage` переполнен, новая метка не появляется как будто сохранённая. Публичные функции снабжены русскими JSDoc-комментариями; экспорт задаёт границы модулей. Импорты образуют направленные зависимости без циклов.

## Данные и фото

Одна метка содержит:

```js
{
  id: "уникальный-id",
  type: "dump",            // dump | bin | bench | subbotnik
  title: "Мусор у парка",  // 3–60 символов после trim
  description: "Нужна уборка", // до 500 символов
  lat: 43.2389,
  lng: 76.8897,
  address: null,            // адрес или null
  photo: null,              // JPEG dataURL или null
  status: "new",            // new | in_progress | resolved
  createdAt: "2026-10-08T10:00:00.000Z"
}
```

`localStorage` хранит JSON-массив по ключу **`ecopatrol_reports`**. При отсутствии ключа создаются пять примеров. Сохранённый массив `[]` означает, что пользователь удалил все метки: примеры заново не добавляются. Повреждённый JSON не перезаписывается примерами; приложение сообщает об ошибке, восстановление возможно импортом корректных данных.

Фото необязательно. Файл должен иметь MIME-тип `image/*` и размер **не более 10 МБ**; браузер должен уметь декодировать его. Для защиты удобно использовать JPEG или PNG. Canvas сохраняет пропорции, уменьшает максимальную сторону до **800 px** и возвращает **JPEG с quality 0.7**. Маленькие фото не увеличиваются; прозрачность заменяется белым фоном. В хранилище попадает строка `data:image/jpeg;base64,...`, а не исходный файл.

Объём `localStorage` ограничен и зависит от браузера; base64 занимает больше места, чем двоичные данные. При ошибке квоты экспортируйте метки, удалите старые или выбирайте меньшие фото.

Экспорт скачивает переносимый JSON со всеми метками, включая фотографии. Для переноса в другой браузер импортируйте этот файл. Импорт принимает **массив** до 5000 меток, файл до 20 МБ. Проверяются обязательные поля, допустимые типы и статусы, границы координат, дата, JPEG dataURL и уникальность `id`. Посторонние поля отбрасываются. Данные объединяются по `id`: новая метка добавляется, совпадающая заменяет прежнюю, остальные прежние метки сохраняются. Если хотя бы одна запись неверна, весь импорт отклоняется до записи.

Данные принадлежат конкретному браузеру и origin — сочетанию схемы, хоста и порта. `localhost:4173` и `127.0.0.1:4173` имеют разные хранилища. `start.py` обычно использует `127.0.0.1:4173`; если этот порт занят и выбран временный, браузер покажет другое хранилище. Возвращайтесь к тому же адресу либо переносите данные экспортом/импортом. В режиме `file://` отображаются учебные примеры, пользовательское хранилище полного приложения не читается.

Очистка данных браузера удаляет метки. Backend, учётных записей и общего списка жителей нет: приложение сохраняет сведения локально, а экспорт делает их переносимыми. Фото и описания из JSON могут содержать личную информацию, поэтому перед передачей файла проверьте его содержимое.

## API и сеть

| Технология / API | Для чего используется |
| --- | --- |
| Leaflet 1.9.4 | Карта, `L.marker`, `L.divIcon`, popup, события клика и анимация `flyTo`. |
| OpenStreetMap | Фон карты: `https://tile.openstreetmap.org/{z}/{x}/{y}.png`. Авторство показано на карте. |
| Nominatim | Адрес → координаты: `https://nominatim.openstreetmap.org/search`. |
| Geolocation API | Координаты устройства с разрешения пользователя. |
| DOM и ES-модули | Разметка интерфейса, события и разделение JavaScript по файлам. |
| Fetch / Promise / async–await | Асинхронные запросы и обработка результатов без блокировки страницы. |
| FileReader и Canvas | Чтение и сжатие выбранного фото в браузере. |
| localStorage / Blob / URL | Сохранение меток и создание скачиваемого JSON. |

Для облачной среды нужны HTTPS-доступы к `unpkg.com`, `tile.openstreetmap.org` и `nominatim.openstreetmap.org`. Сервер для собственных API не требуется. Адрес поиска передаётся Nominatim, запросы тайлов — OpenStreetMap; отчёты и фото приложение этим сервисам не отправляет.

Nominatim получает параметры `format=json`, `limit=1`, `countrycodes=kz`, `accept-language=ru` и введённый `q`. Поиск запускается только кнопкой или отправкой формы: **автодополнения нет**. Обычный поиск и демо используют один экземпляр геокодера: один активный запрос и интервал между началами не менее 1100 мс, кнопки блокируются на время операции. Тайм-аут запроса — 12 секунд.

Политика публичного Nominatim устанавливает суммарный предел **1 запрос в секунду для приложения**. Общий ограничитель в этом учебном проекте действует в пределах одной открытой страницы. Для массового размещения с несколькими вкладками или пользователями понадобятся общий серверный ограничитель и кеш либо собственный/другой сервис геокодинга. Политики: [Nominatim](https://operations.osmfoundation.org/policies/nominatim/), [тайлы OpenStreetMap](https://operations.osmfoundation.org/policies/tiles/).

Если адрес не найден, укажите город, улицу и номер дома в Казахстане. При отсутствии интернета или ошибке сервиса появляется сообщение, данные не теряются. Если Leaflet не загрузился, список меток остаётся доступен; если не загрузились тайлы, приложение предупреждает об отсутствии фона. При отказе геолокации можно выбрать место кликом или поиском.

## Демонстрация на защите: 2–3 минуты

Перед выступлением проверьте интернет, подготовьте небольшое фото и подходящий адрес в Алматы. Откройте проект с тем же origin, на котором готовили метки. Для повторной защиты сохраните резервную копию через «Экспорт JSON».

1. **0:00–0:20 — карта и примеры.** Покажите Алматы, пять учебных меток, цветовую легенду и счётчики. Объясните цель «Таза Қазақстан»: жители замечают проблемы и отмечают их на карте.
2. **0:20–0:55 — метка кликом с фото.** Кликните по карте, выберите тип, введите заголовок, добавьте фото и сохраните. Откройте popup и покажите изображение. Скажите, что браузер сжал фото до 800 px.
3. **0:55–1:20 — поиск адреса.** Введите, например, «Алматы, улица Абая, 10», нажмите «Найти». Покажите перелёт к временному маркеру и сохраните обычную метку. Результат зависит от данных Nominatim.
4. **1:20–1:55 — спросите зал.** Нажмите «🎤 Демо: спросить зал», введите адрес от слушателей и нажмите «Поставить маркер». Покажите зелёный пульсирующий маркер и popup «Здесь нужен субботник!». При неизвестном адресе уточните его и повторите поиск.
5. **1:55–2:20 — фильтры и статус.** Оставьте один тип, выполните текстовый поиск, сбросьте фильтры. В popup нажмите «Изменить статус» и покажите изменение счётчиков. Перезагрузите страницу, чтобы продемонстрировать сохранение.
6. **2:20–2:50 — объясните код.** В `geocoder.js` покажите URL-параметры, `await fetch`, проверку ответа, тайм-аут и общий ограничитель. В `map.js` — `L.divIcon`, `render`, безопасное создание popup и `flyTo`.

Геолокацию лучше проверить заранее: в помещении точность может быть низкой, а браузер вправе запросить разрешение или отказать.

## Возможные вопросы преподавателя

| Вопрос | Краткий ответ |
| --- | --- |
| Что такое DOM? | Дерево объектов, представляющих HTML-страницу. JavaScript находит узлы, меняет `textContent`, добавляет элементы и обработчики событий. |
| Как работает `fetch`? | Выполняет сетевой запрос и возвращает Promise с `Response`. `await` ждёт результат, `response.ok` проверяет HTTP-статус, `response.json()` читает JSON. HTTP-ошибка сама по себе не отклоняет Promise. |
| Зачем `async/await` и `try/catch`? | Они позволяют читать асинхронный код последовательно и отдельно обрабатывать сетевые, файловые и другие ошибки; `finally` восстанавливает кнопки. |
| Зачем `escapeHtml`? | Превращает специальные символы в HTML-сущности, если нужен HTML-шаблон. Здесь пользовательский текст выводится через `textContent` — это безопаснее и не требует экранирования. `escapeHtml` оставлен как учебная утилита. |
| Почему `<script>` в описании не выполняется? | Описание становится текстом DOM-узла, а не HTML-разметкой. Данные импорта тоже проверяются, фото допускается только как JPEG dataURL. |
| Чем `localStorage` отличается от cookies? | `localStorage` хранит строки в браузере для конкретного origin и не отправляется автоматически с HTTP-запросами. Cookies могут отправляться серверу, имеют срок жизни и атрибуты доступа. Оба механизма требуют учитывать приватность. |
| Что такое геокодинг? | Преобразование адреса в широту и долготу. Обратный геокодинг преобразует координаты в адрес; в этом проекте он не используется. |
| Как сжимается фото? | `FileReader` читает файл, `Image` декодирует его, canvas рисует уменьшенную копию, `toDataURL('image/jpeg', 0.7)` возвращает JPEG в base64. |
| Почему ES-модули? | Каждый файл экспортирует нужные функции и импортирует зависимости. Это разделяет ответственность и позволяет браузеру запускать проект без сборщика. |
| Где находятся данные других жителей? | Их нет на общем сервере: это локальная учебная версия. Для общего доступа нужны backend, база данных, права доступа и серверная валидация. |
| Можно ли полностью работать без интернета? | Уже сохранённые метки находятся локально, но Leaflet загружается с CDN, а фон карты и геокодинг требуют сети. Service worker и офлайн-кеш здесь не реализованы. |
